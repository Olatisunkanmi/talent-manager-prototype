# Talent Manager

Money back office for a talent and influencer management agency (Nigeria, Naira only).

Status: documentation and prototype only. No application code yet.

- `docs/prd.md`: product requirements
- `docs/features/*.frd.md`: one requirements doc per feature (talents, campaigns, expenses, advances, invoices, payouts, company overview, company settings, auth, WhatsApp assistant, post insights, inbox inquiry tracking, campaign tasks, campaign notes, team management)
- `docs/challenge-resolutions.md`: outcome of the adversarial review of the PRD and FRDs
- `design/context.md`: design tokens and direction
- `design/mockup-static.html`: earlier static mockup
- `prototype/index.html`: clickable prototype. Open it in a browser; data is stored locally and email, PDF, WhatsApp and platform APIs are simulated.
